# Better Turkish Translation For Minecraft

Minecraft için özel isimlendirmeler ve detaylı düzenlemeler içeren geliştirilmiş Türkçe kaynak paketi.

## V1.2 Sürüm Yenilikleri 

* **Yenilenen Başarımlar:** Oyundaki Tüm Başarımların elden geçirildi.
* **Gelişmiş Item İsimlendirmeleri:** Oyuna 1.21.6 ile eklenen adı "Dizgin" olan item adı "Ghast Eyeri" olarak değiştirildi.
* **Genel İyileştirmeler:** Bazı Sıkıntılı Düzeltmeler, Eksiklikler giderildi.

## Kurulum

1. Bu depodan veya [Modrinth]([https://modrinth.com/resourcepack/better-turkish-translation]) sayfasından kaynak paketinin `.zip` dosyasını indirin.
2. Minecraft'ı açın ve **Seçenekler (Options)** > **Kaynak Paketleri (Resource Packs)** menüsüne gidin.
3. **Paket Klasörünü Aç (Open Pack Folder)** butonuna tıklayın.
4. İndirdiğiniz `.zip` dosyasını bu klasörün içine atın.
5. Oyuna geri dönün, paketi aktif listeye taşıyıp onaylayın.
